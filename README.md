# Sowing Seeds of Hope Africa

Photo-forward marketing site for the nonprofit supporting schools, medical care, and school-fee help in Uganda and Kenya.

## Stack

- Vite + React + TypeScript
- React Router
- Brand photos in `public/images`

## Develop

```bash
npm install
npm run dev
```

## Notes

- Homepage hero and welcome photos come from the existing Wix site.
- Uganda pages use the newer field photos, including a fading gallery every 2 seconds.
- Update `src/site.ts` with the live domain, email, and phone before launch.
- Donation cards currently route to the contact form until a payment processor is connected.
